# 资源库与 Dock 玻璃使用与测试（1.3.0~lock14）

用户已在 iPhone 14 Pro / iOS 16.6 确认 lock11 通知玻璃观感良好。lock13 实机截图显示资源库与 Dock 的上下高光过亮、过匀，形成白色粗边，主体上下亮带也偏灰白。lock14 针对这些问题收敛绘制；新效果仍需同机实测。

## 这次调整

- 分类卡片、搜索框和玻璃模式 Dock 使用专用的上下高光。上下边保持主要反光，同时沿宽度柔和起伏，到圆角处进一步减弱；两侧中部保留轻微连续轮廓，避免只剩两条分离的亮线。
- 主反光取消平顶亮芯，从边缘立即平滑渐隐。分类卡片主反光目标宽度 1.35 pt、低强度亮肩 2.4 pt；搜索框分别为 1.0 / 1.8 pt，Dock 为 1.4 / 2.3 pt，宽度向上对齐屏幕像素。主反光峰值由 0.52 降到 0.34，亮肩峰值由 0.22 降到 0.11；内阴影同步减轻。
- 亮边共用原生连续圆角外轮廓，以经过透明度补偿的重叠边框减少圆角接缝。图层重复使用，不生成卡片位图或添加逐帧定时器。
- 主体大幅减轻 lock13 的上下白色亮带，保留低密度中性层次，背景扩大采样后在外轮廓裁切。Clear 固定 10 pt 模糊，Liquid Glass 固定 8 pt；Dock 固定 10 pt，采用独立的背景采样组。滤镜不可用时降级到系统材质。
- 资源库保留“跟随文件夹 / Clear / Liquid Glass”；跟随只决定样式，文件夹强度不联动资源库。Dock 参数独立于文件夹和资源库样式。
- 保留 Dock 独立开关与“隐藏背景 / 玻璃效果”；关闭后恢复保存的系统背景状态。系统继续处理图标、文字、触摸与背景显示动画。
- 锁屏、通知横幅与文件夹绘制沿用已有实现，授权流程与密钥沿用。

## 开启方式

1. 选择与越狱环境匹配的 lock14 DEB 覆盖升级，重新载入桌面一次以加载新版代码。RootHide 与标准 Rootless 二选一。
2. 已有授权和设置继续使用，无需重新签发；未激活的设备先在“授权管理”完成激活。
3. 在“设置 → GlassFolders”打开“App 资源库”，选择“跟随文件夹 / Clear / Liquid Glass”。资源库开关默认关闭，升级保留已有选择。
4. 如需 Dock 玻璃，打开 Dock 独立开关并选择“玻璃效果”。选择“隐藏背景”时不显示自定义玻璃；关闭独立开关恢复系统背景。
5. 日常切换开关或样式通过现有设置通知立即刷新，不需要每次注销。文件夹透明度／强度滑杆不会改变资源库或 Dock 的固定光学参数。

## 实机检查

- 同壁纸检查资源库卡片上下边是否消除粗白描边、两侧轮廓是否连续、圆角是否连续、内侧渐隐是否干净；再换亮暗壁纸检查是否发白或显得沉闷。
- 上下滚动资源库、返回主屏、展开分类并返回，检查背景跟随、裁切和动画中是否短暂出现双层底板。
- 搜索输入和删除文字、显示键盘、取消搜索并重新进入，检查搜索图标、文字和按钮可见且能正常操作。
- 分别切换 Clear、Liquid Glass、跟随文件夹及系统明暗模式，检查卡片与搜索框刷新；修改文件夹强度时资源库和 Dock 应保持固定参数。
- Dock 依次切换玻璃、隐藏背景、关闭；检查上下高光、圆角收尾、原生背景恢复、图标点击和长按，以及锁屏进入主屏和应用切换时的淡入淡出。
- 资源库开关关闭后确认系统底板恢复；检查锁屏通知、音乐、实时活动、圆按钮与通知横幅是否保持原有效果。

包声明的目标系统为 iOS / iPadOS 16.0–17.3.1。构建与包内容检查用于确认可编译和打包正确，不能代替上述实机视觉及交互验证，也不代表所有目标版本均已测试。
