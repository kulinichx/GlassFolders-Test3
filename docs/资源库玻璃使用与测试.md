# 资源库玻璃使用与测试（1.3.0~lock12）

用户已在 iPhone 14 Pro / iOS 16.6 确认 lock11 玻璃观感良好。lock12 将该版本的边缘画法用于 App 资源库分类卡片和顶部搜索框，资源库的新效果仍需同机实测。

## 这次调整

- 分类卡片与搜索框使用和 lock11 卡片相同的连续圆角高光：1.6 pt 紧凑反光、自然渐隐的亮肩和浅内阴影。根据各自原生尺寸与圆角适配，不强行改变卡片形状。
- 移除旧资源库的大面积角落泛光、独立细描边及叠加的原生底板。背景先扩大采样，再在卡片外轮廓裁切；主体只保留低强度中性渐变，减少内部灰白雾感。
- Clear 使用固定 10 pt 模糊；Liquid Glass 使用固定 8 pt 模糊和更轻的主体。两者均采用同一套高光，明暗模式保留轻微密度区别；背景滤镜不可用时降级为系统材质。
- 图标、分类名称、搜索输入和原有操作继续由系统处理。关闭资源库开关后移除自定义玻璃，并恢复已保存的原生底板透明度。
- 锁屏和通知横幅使用的高光实现原样移入共享文件，参数及其他绘制流程沿用 lock11；文件夹、Dock 与授权流程沿用。

## 开启方式

1. 选择与越狱环境匹配的 lock12 DEB 覆盖升级，重新载入桌面一次以加载新版代码。RootHide 与标准 Rootless 二选一。
2. 已有授权和设置继续使用，无需重新签发；未激活的设备先在“授权管理”完成激活。
3. 在“设置 → GlassFolders”打开“App 资源库”，选择“跟随文件夹 / Clear / Liquid Glass”。资源库开关默认关闭，升级保留已有选择。
4. 日常切换开关或样式通过现有设置通知立即刷新，不需要每次注销。“跟随文件夹”只跟随样式，文件夹透明度／强度滑杆不会改变资源库模糊和高光。

## 实机检查

- 在原壁纸下对比卡片左上、右下高光厚度和圆角连续性；再换亮、暗壁纸检查主体通透度、边缘是否发白。
- 上下滚动资源库、左右返回主屏、展开分类并返回，检查背景跟随、裁切和动画中是否短暂出现双层底板。
- 点击搜索框，输入和删除文字、显示键盘、取消搜索并重新进入，检查搜索图标、文字及按钮可见且能正常操作。
- 分别切换 Clear、Liquid Glass、跟随文件夹以及系统明暗模式，检查卡片与搜索框同步刷新；修改文件夹强度时资源库应保持固定效果。
- 在资源库开启与关闭时各检查一次，确认原生底板恢复；检查锁屏通知、音乐、实时活动、圆按钮与横幅是否仍保持 lock11 效果。

包声明的目标系统为 iOS / iPadOS 16.0–17.3.1。构建与包内容检查用于确认可编译和打包正确，不能代替上述实机视觉及交互验证，也不代表所有目标版本均已测试。
