# GlassFolders 安装状态与激活指南

## 你现在手里的安装包是什么状态？

本次工作有两个不同版本，不能混在一起判断：

| 版本 | 当前是否有安装包 | 是否需要授权 | 安装后的表现 |
| --- | --- | --- | --- |
| 原版 `1.0.0-fix1` | 有，工作目录中的旧 `.deb` | 不需要本次新增授权 | 继续按原版开关和设备环境运行；本次没有修改这个旧安装包 |
| 新授权候选版 `1.1.0~license2` | GitHub Actions 构建，提供 RootHide 与标准 rootless 两种包 | 需要独立 GlassFolders 授权 | 首次安装未激活时，设置页可以打开，但文件夹和资源库的玻璃效果都不会启用 |

因此，如果你现在安装的是原来的 `1.0.0-fix1.deb`，它不会因为这次源码修改而突然要求授权。它如果没有效果，不能归因于本次新增的授权功能，需要检查原版开关、插件注入与包类型是否匹配。

下面的激活流程仅适用于新授权版。当前已有手机绑定流程的测试反馈，完整激活与玻璃效果仍需真机确认，请勿把旧包当成新授权版测试。

## 新授权版安装后会怎样？

`1.1.0~license2` 将授权操作移入独立“授权管理”页面。首页下方“关于”分组只显示“授权管理 · 已激活 / 未激活”入口；未激活时，顶部额外显示简短的“前往激活”提示，激活后自动隐藏。文件夹、资源库、样式和强度仍在首页。

授权详情页未激活时显示三个步骤，复制设备码和生成回执成功后显示完成标记。已激活时显示状态、授权编号和“本机永久授权”，操作步骤收起到“更换授权”；更换过程中原授权保留，可以取消。红色“移除授权”位于详情页底部，仍需确认。“应用并注销”在首页和授权详情页都可使用。

- **首次安装 / 未激活**：设置页显示“未激活”；文件夹与资源库玻璃效果均不启用。开关打开也不能跳过授权。
- **授权无效、授权被改动或属于另一台设备**：拒绝激活，显示对应提示；不会获得玻璃效果。
- **激活成功**：设置页显示“已激活”和授权编号。点击“应用并注销”，然后按自己的需要开启“文件夹”或“资源库”。默认文件夹开关为开、资源库开关为关，授权不会强制打开这两个开关。
- **下次重启 / 重新越狱**：只要同一台设备上保存的授权仍有效、插件注入正常，代码会自动校验，不需要每次手动签发。
- **移除授权**：点击“移除授权”确认，再“应用并注销”，文件夹和资源库恢复系统效果。已显示的旧玻璃背景可能要注销后才完全清除。
- **升级**：从旧版升级到新授权版，如果没有对应授权，就需要先完成激活；已有设置会保留，但不会因此免除授权。同产品、同公钥的新版本可继续识别已保存的授权。

这里的“注销”指重启桌面 SpringBoard，不是退出 Apple ID。

## 怎样授权？

### 第一步：手机复制设备码

安装新授权版后，进入“设置 → GlassFolders → 授权管理”（未激活时也可点顶部“前往激活”），点击“1. 复制设备码”，把完整设备码发给签发者。设备码以 `GF-` 开头。

### 第二步：电脑生成绑定码

签发者双击 `GlassFolders-Issuer\GlassFolders签发器.exe`，填写授权编号、用户名称和手机设备码。用户名称必填，可填昵称；联系方式 / 备注选填，可填 QQ、微信或订单号。点击“1. 生成绑定码并复制”，把复制出的绑定码发回手机。

### 第三步：手机生成设备回执

手机保持解锁，在“授权管理”页面点击“2. 绑定本机”，粘贴绑定码，点击“生成并复制设备回执”，把回执发回签发者。

### 第四步：电脑验证并签发

签发者先复制收到的回执，再点击“2. 粘贴回执并验证”。验证通过后，点击“3. 签发授权并复制”，把授权发给手机。

**从生成绑定码开始，整个绑定和签发过程需要在五分钟内完成。** 过期就重新生成绑定码，再重新生成回执。不能拿旧回执配合新绑定码使用。

如果刚生成就提示“绑定码已过期或设备时间不正确”，请使用电脑签发器 **1.1.1**。旧版在北京时间环境下存在 8 小时时间偏移。关闭旧窗口，重新打开更新后的签发器，生成新的绑定码，从本步骤重新开始；此问题不需要重装手机 DEB。电脑和手机的实际日期时间仍需正确。

### 第五步：手机激活并注销

手机点击“3. 粘贴授权”，粘贴以 `GF1.` 开头的完整授权并激活。显示成功后点击“应用并注销”，回到桌面确认效果。

如果是你自己给自己的设备签发，就在手机和电脑之间按上述顺序复制对应内容即可，不需要授权服务器。

## 哪些事情不用重复做？

最终授权是永久设备授权，没有订阅到期时间。**五分钟是绑定码的有效期，不是插件只能使用五分钟。** 正常关闭签发器、手机重启、重新越狱，都不需要重新签发。删除插件配置、恢复设备或更换设备后，可能需要重新粘贴原授权或重新签发。

点击签发器底部“查看历史授权 / 用户资料”，可按用户、联系方式 / 备注、授权编号和设备码搜索。选中记录可查看完整设备码与授权码、复制授权，也可补填旧记录的用户资料。列表中的签发时间按电脑本地时区显示。

用户资料只保存在电脑本地，不写入发送到手机的授权码。修改用户资料不会影响原授权的使用。RC7 授权不能用于 GlassFolders。不要把电脑签发工具或私钥目录发送给用户，用户只需要自己的绑定码和最终授权。

## 签发器现在如何启动？

直接双击 `GlassFolders-Issuer\GlassFolders签发器.exe`。这是无控制台的图形入口，直接显示签发界面，不需要先打开 CMD。关闭签发界面后后台进程会退出；启动失败时显示提示框。

启动器与签发程序文件应保留在同一文件夹；同级 `GlassFolders-Issuer-Private` 保存当前正式密钥和签发记录。不要删除或重新初始化该目录。

## 支持哪些系统？

本候选版目标为 **iOS / iPadOS 16.0–17.3.1**，还需要该设备和系统上可用的越狱、SpringBoard 插件注入及 PreferenceLoader。RootHide 环境用 RootHide 包，标准 rootless 环境用标准 rootless 包。

目前已做代码检查与 Windows 签发器检查，完整激活及玻璃效果仍需真机测试，不能将适配目标理解为所有机型均已确认可用。详细兼容性说明见同目录《离线授权与兼容性.md》。
