# Dock 使用与测试（1.2.0~dock1）

设置 → GlassFolders → Dock 栏：开启“自定义 Dock”，再选择“隐藏背景”或“玻璃效果”。关闭开关恢复系统 Dock 背景。升级时默认关闭，不改变已有的文件夹、资源库配置。

- **隐藏背景**：隐藏系统 Dock 底板，保留图标与正常操作。
- **玻璃效果**：用固定强度的 Liquid Glass 材质替换底板，自动适配明暗外观，不跟随文件夹滑杆。
- **授权**：沿用已保存的 GlassFolders 授权，无需重新签发。没有有效授权时，Dock 不接管系统背景；文件夹、资源库、Dock 均使用同一份授权，但开关独立。

## 安装前

先停用或卸载旧“隐藏 Dock 背景”插件（包名 `cn.llld.ycdock`），以及其他接管 Dock 背景的插件，再安装对应越狱环境的 DEB 并注销桌面。旧插件会持续隐藏背景，不能用两者同时开启的状态判断新玻璃效果是否正常。

RootHide 环境选 RootHide 包；标准 rootless 环境选 Rootless 包。两种包不要混装。目标系统仍为 iOS / iPadOS 16.0–17.3.1，需支持插件注入的越狱环境；这不是完整的真机兼容性结论。

更改 Dock 设置会通知桌面刷新；如未立即变化，点击“应用并注销”。注销仅重启桌面，不退出 Apple ID。

## 真机验收

构建检查可验证编译、架构和设置资源，以下项目需在手机 / 平板上实际确认：

1. 原版本已激活的设备直接升级，授权仍显示已激活；Dock 默认保持系统背景。
2. 打开 Dock 开关，选择隐藏背景；底板消失，图标、长按菜单、拖动及打开应用正常。
3. 切到玻璃效果；底板出现玻璃材质，明暗模式、浅色和深色壁纸下均无重影。
4. 关闭 Dock 开关；系统底板恢复，重复切换两种效果不会叠加材质。
5. 分别关闭文件夹与资源库，Dock 开关与样式仍独立生效；修改文件夹样式/强度不会改变 Dock 配方。
6. 打开 / 退出应用、进入 / 退出文件夹、横竖屏切换、重新注销后，底板尺寸、圆角及淡出状态正常。平板浮动 Dock 单独测试。
7. 在未激活的测试设备上打开 Dock 开关，系统背景保持原状；移除授权并注销后恢复系统背景。

实现只针对 `SBDockView` / `SBFloatingDockPlatterView` 的背景视图，不接管 Dock 图标、手势或布局。未知背景结构会跳过处理。没有定时器、常驻服务或逐帧轮询。
